# strukdat8

Visualisasi data dengan Matplotlib dan Streamlit.

- Soal 1: data penjualan dari file Excel (`penjualan.xlsx`)
- Soal 2: data Pokémon dari PokeAPI

## Menjalankan

```
uv sync
uv run streamlit run main.py
```

## Upload ke GitHub

```
git init
git add .
git commit -m "tugas strukdat8"
git branch -M main
git remote add origin https://github.com/USERNAME/strukdat8.git
git push -u origin main
```
